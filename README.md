# 📬 Mail.Ru 2010 Revival (soap)

Аутентичная реконструкция портала **Mail.Ru** образца **2010 года** с живыми информерами, веб-поиском по всему интернету, классической мобильной версией (`m.mail.ru`), ретро-баннерами и 88×31 кнопками.

## ✨ Особенности проекта

### 🖥️ 1. Главная страница (`index.html`)
- **Оригинальная вёрстка 2010 года**: табличная структура, классические шрифты (Arial/Tahoma), монолитные блоки авторизации, информеров и проектов.
- **Живая погода**: автоматическое определение города по IP через Open-Meteo API с выводом температуры за окном, иконки погоды и прогноза на вечер/завтра.
- **Курсы валют**: реальные курсы доллара и евро с расчётом дельты относительно предыдущего дня от ЦБ РФ.
- **Свежие новости**: динамическая подгрузка из RSS с мгновенным переключением вкладок без перезагрузки страницы (*Хабр*, *Авто*, *Афиша*, *Hi-Tech*, *Леди*, *Игры*).
- **Телепрограмма**: автоматическое определение текущей передачи в реальном времени для каналов *Первый*, *Россия 1*, *НТВ*.
- **Интеграция с ретро-сервисами**:
  - Вкладка Мой Мир и блок игр ведут на [OpenVK](https://openvk.org/) и [OpenVK Apps](https://openvk.org/apps).
  - Renaissance ведёт на ретро-клиент [MRIM.su (Renaissance)](http://mrim.su/).

### 🔍 2. Полноценный поисковик (`search.html`)
- Воссоздана оригинальная тёмно-синяя панель поиска со скошенным полем ввода, кнопкой **«Найти»**, иконкой лупы и значком русской клавиатуры.
- Вкладки сервисов строго зафиксированы в одну горизонтальную строку с горизонтальным скроллом.
- **Поиск по всему интернету**: интеграция с DuckDuckGo Web Instant API и параллельными быстрыми CORS-прокси (с парсингом сниппетов, заголовков, фавиконок и прямых ссылок сайтов).

### 📱 3. Мобильная версия (`m.html` / `m/`)
- Точная копия классического `m.mail.ru` 2010–2014 годов по историческому дизайну.
- Все иконки сервисов и категорий нарезаны из оригинальных спрайтов десктопной версии.
- Блоки: *Главные новости*, *Погода*, *Курсы валют*, *Спорт*, *Афиша*, *Игры* (ссылки на [OpenVK Apps](https://openvk.org/apps)), *Программы для телефона* (без устаревшего ICQ), *Все проекты* в две колонки.
- Автоматическое переключение для пользователей смартфонов с возможностью возврата к полной версии (`index.html?full=1`).

### 💬 4. Чат@Mail.Ru (`chat.html`)
- **Аутентичный ретро-чат 2010 года**: комнаты («Беседка», «Знакомства и флирт», «Музыка и Кино», «Hi-Tech и Игры»), список собеседников с полом/статусами, приватные сообщения («приватно для...»), классические колобки-смайлы и звуковые эффекты.
- **Шифрование всей информации в txt-файле**: вся база сообщений, пользователей и настроек хранится исключительно в зашифрованном виде (AES-256-CBC + SHA-256) в файле `chat_data.txt`.
- **Защита от спама**: флуд-контроль (кулдаун 2.5 сек), запрет отправки дубликатов сообщений, фильтр Caps Lock и повторяющихся символов, автоматический мут на 60 секунд при превышении лимитов.
- **Двухрежимная работа**:
  - Автономный бэкенд на Node.js (`node chat_server.js`) с прямой синхронизацией зашифрованного файла на диске.
  - Полная поддержка статического хостинга (GitHub Pages) с клиентом `chat_crypto.js`, кросс-вкладочной синхронизацией `BroadcastChannel` и базой в `chat_data.txt`.

### 🎨 5. Баннеры и 88×31 кнопки
- Встроенный динамический ротатор баннеров (*Inori Aizawa*, *LunaStore*, *Renaissance*, *FaeroFM*, *faero.top*).
- Аутентичный блок кнопок 88×31 в футере страниц.

### 🌐 6. Универсальная совместимость (HTTP и HTTPS)
- Все запросы, скрипты и ссылки работают прозрачно как по `http://`, так и по `https://`, исключая ошибки Mixed Content.

### 🤖 7. Android-клиент soap (Eclipse ADT, Android 1.6 – Android 16)
- Проект в папке `android/` по стандарту **Eclipse ADT**: собирается как в классическом Eclipse (Helios/Juno/Kepler) и через Ant, так и в современном Android Studio / Gradle.
- Запускается на раритетных устройствах с **Android 1.6 Donut (API 4)** благодаря обходу старых SSL-сертификатов и безопасным настройкам `WebSettings`.
- Полностью совместим с современными **Android 9–16** благодаря поддержке `usesCleartextTraffic`, `network_security_config.xml`, `org.apache.http.legacy` и строгому 4-байтовому выравниванию (`zipalign`).
- Фирменная тёмно-синяя шапка с кнопками навигации, переключателем между мобильной и полной версией и офлайн-экраном.

## 🚀 Запуск и хостинг

Так как проект полностью статический, запустить его можно любым удобным способом:

### Быстрый локальный запуск (Python):
```bash
# В корне проекта:
python -m http.server 8000
```
После запуска откройте в браузере: `http://localhost:8000`

### Запуск через Nginx / Apache / Caddy:
Просто поместите файлы репозитория в корневую директорию вашего веб-сервера (например, `/var/www/html/`).

### GitHub Pages:
1. Перейдите в **Settings** вашего репозитория на GitHub.
2. В разделе **Pages** выберите ветку `main` и корневую папку `/ (root)`.
3. Сохраните изменения — сайт станет доступен по адресу `https://<username>.github.io/<repo>/`.
