Часто задаваемые вопросы (FAQ):

❓ Что представляет собой soap.nekxd.fun?
Это ретро-портал — живая реконструкция классического Mail.Ru образца 2010 года. Проект работает полностью на стороне клиента (статичный HTML/CSS/JS), без серверного бэкенда, подтягивая реальные данные через открытые API.
🔍 Как работает поиск по интернету?
Поиск на странице search.html интегрирован с DuckDuckGo Instant Web API и несколькими параллельными CORS-прокси. Он выдает реальные результаты поиска, сниппеты, прямые ссылки сайтов и фавиконки.
⛅ Откуда берутся погода, новости и курсы валют?
Погода определяется автоматически по вашему IP через Open-Meteo API. Курсы доллара и евро обновляются ежедневно по официальным данным Центробанка РФ. Новости транслируются в реальном времени из RSS-лент Хабра.
💬 Что такое Renaissance?
Renaissance (MRIM.su) — это современный проект возрождения легендарного протокола и мессенджера Mail.Ru Агент, где можно зарегистрироваться и общаться с единомышленниками.
📱 Есть ли версия для мобильных телефонов?
Да! Доступна точная реплика мобильного портала m.mail.ru тех лет. При входе со смартфона редирект происходит автоматически, либо вы можете открыть m.html вручную.
📢 Как обменяться кнопками 88×31 или баннерами?
Все коды для размещения наших кнопок и условия размещения ваших баннеров находятся на странице Реклама на soap.nekxd.fun.
